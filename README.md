# ملتقى — منصة وظائف السودان

مشروع Next.js كامل + Firebase + PWA. شغال في المتصفح والموبايل، وقابل للتحويل لتطبيق أندرويد يترفع في Google Play.

---

## المرحلة 1: تشغيل المشروع على جهازك

### المتطلبات
- Node.js نسخة 18 أو أحدث (نزّله من nodejs.org لو ما عندك)

### الخطوات
```bash
cd multaqa-app
npm install
```

هذا هيثبت كل المكتبات المطلوبة (Next.js وFirebase وlucide-react وTailwind).

---

## المرحلة 2: ربط Firebase (قاعدة البيانات)

1. روح إلى https://console.firebase.google.com
2. اضغط **Add project** واختر اسم زي `multaqa-sudan`
3. من القائمة الجانبية اختر **Build > Firestore Database** ثم **Create database**
   - اختر **Start in production mode**
   - اختر أقرب موقع سيرفر (مثلاً `europe-west` أو `me-west1` لو متاحة)
4. بعد إنشاء قاعدة البيانات، روح **Rules** وانسخ محتوى ملف `firestore.rules` الموجود في المشروع، الصقه، واضغط **Publish**
5. من نفس المشروع، روح **Project settings** (أيقونة الترس) > **General** > انزل لتحت لـ **Your apps** > اضغط أيقونة **</>`Web`**
6. سمّي التطبيق `multaqa-web` واضغط **Register app**
7. هتظهر لك قيم `firebaseConfig` — انسخها

### تعبئة المفاتيح
```bash
cp .env.local.example .env.local
```
افتح `.env.local` وعبي كل قيمة من الـ `firebaseConfig` اللي نسخته (بدون علامات اقتباس).

## المرحلة 3: التشغيل محلياً

```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000` — لازم تشوف التطبيق شغال، وأي وظيفة تنشرها هتنحفظ فعلياً في Firestore وتظهر لأي حد يفتح نفس الرابط.

جرّب تفتحه من موبايلك (لازم يكون الموبايل والكمبيوتر على نفس الشبكة، واستخدم رابط الـ IP اللي يظهر لك في الطرفية بدل localhost) — من متصفح الموبايل اضغط قائمة المتصفح واختر **إضافة إلى الشاشة الرئيسية** وهيتثبت زي تطبيق عادي (PWA).

## المرحلة 4: نشره على الإنترنت (Vercel — مجاني)

1. ارفع المشروع على GitHub (حساب مجاني لو ما عندك)
2. روح https://vercel.com وسجل دخول بحساب GitHub
3. اضغط **Add New > Project** واختر الريبو بتاعك
4. في خطوة الإعدادات، أضف نفس متغيرات `.env.local` تحت **Environment Variables**
5. اضغط **Deploy**

هتحصل على رابط زي `https://multaqa.vercel.app` — ده الموقع الحقيقي شغال لأي حد في السودان أو برّه.

---

## المرحلة 5: تحويله لتطبيق أندرويد يترفع في Google Play

بعد ما يبقى عندك رابط حقيقي شغال (من المرحلة 4)، استخدم **PWABuilder** (أداة مجانية من مايكروسوفت مخصصة بالضبط لهذا):

1. روح https://www.pwabuilder.com
2. حط رابط موقعك (`https://multaqa.vercel.app`) واضغط **Start**
3. الأداة هتفحص الـ `manifest.json` و service worker تلقائياً (المشروع مجهز بيهم مسبقاً)
4. اضغط على **Android** package
5. عبي:
   - **Package ID** مثلاً `com.multaqa.app`
   - **App name**: ملتقى
   - ارفع نفس أيقونات المشروع من `public/icons/`
6. اضغط **Generate** — هتنزل ملف `.aab` (Android App Bundle) جاهز

### الرفع لـ Google Play
1. روح https://play.google.com/console وسجل حساب مطور (رسوم 25$ لمرة واحدة فقط)
2. اضغط **Create app**، عبي الاسم والوصف والفئة (Business/Jobs)
3. ارفع ملف الـ `.aab` اللي نزلته من PWABuilder
4. عبي **Store listing**: صور شاشة (Screenshots)، أيقونة، وصف قصير وطويل، سياسة الخصوصية (رابط بسيط يشرح إنك بتخزن بيانات الوظائف والتواصل فقط)
5. اضغط **Submit for review** — المراجعة عادة تاخد من يوم لعدة أيام

> ملاحظة: خطوات المراجعة والموافقة من جوجل بتصير من طرفهم، وما فيها أي تدخل مني — بس الكود والملفات كلها جاهزة عشان توصل لهذه المرحلة بأقل عناء.

## هيكلة المشروع

```
multaqa-app/
  app/                  صفحات Next.js (App Router)
  components/           مكونات الواجهة (بطاقة وظيفة، فورم النشر، تفاصيل الوظيفة)
  lib/                  الاتصال بـ Firebase + دوال مساعدة
  public/               الأيقونات وملف الـ manifest وservice worker
  firestore.rules       قواعد أمان قاعدة البيانات
```

## أفكار للمرحلة القادمة (اختياري)
- تسجيل دخول حقيقي (Firebase Auth برقم الهاتف) بدل الاعتماد على تخزين محلي في المتصفح
- إشعارات فورية (Push Notifications) لما يوصل رد على وظيفتك
- تقييم لأصحاب العمل من الباحثين عن شغل
